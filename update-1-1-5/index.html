How to install

  1. Temporarily quit the current Stonespace Browser so Command-3 is available.
  2. Open the downloaded DMG.
  3. Drag Stonespace Input Test into the Applications folder.
  4. Open Stonespace Input Test and test Command-3, clicking, and typing.
  5. When finished, quit the test and reopen the normal Stonespace Browser.

The production Stonespace Browser remains unchanged. This test installs as a separate app.
